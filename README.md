# 🏥 מערכת ניתוח נתוני מטופלות - מרפאת כאבי גב

מערכת מתקדמת לעיבוד, איחוד וניתוח נתוני מטופלות ממרפאת כאבי גב, עם Dashboard אינטראקטיבי וויזואליזציות על ציר הזמן.

## 🎯 תכונות עיקריות

- ✅ **איחוד קבצי JSON** - העלאה ואיחוד של מספר קבצי JSON למערכת אחת
- 🔍 **זיהוי כפולים** - זיהוי אוטומטי של רשומות כפולות
- 👥 **זיהוי שמות דומים** - מציאת שמות דומים שעלולים להיות אותה מטופלת
- 📊 **סטטיסטיקות** - ניתוח מקיף של הנתונים
- 📈 **ויזואליזציה על ציר זמן** - מפת פעילות מרובדת לאורך השנים
- 📋 **טבלת נתונים אינטראקטיבית** - סינון, מיון והורדה של נתונים
- 💾 **ייצוא נתונים** - שמירת נתונים מאוחדים ב-JSON ו-CSV

## 📦 התקנה

### דרישות מקדימות
- Python 3.8 ומעלה
- pip (מנהל חבילות Python)

## 📝 פורמט קובץ JSON

### דוגמה בסיסית

```json
[
  {
    "name": "שרה כהן",
    "date": "2023-01-15",
    "age": 45,
    "diagnosis": "כאב גב תחתון",
    "treatment": "פיזיותרפיה",
    "notes": "טיפול ראשון"
  },
  {
    "name": "דוד לוי",
    "date": "2023-01-20",
    "age": 52,
    "diagnosis": "דיסק",
    "treatment": "עיסוי רפואי",
    "notes": "המשך טיפול"
  }
]
```

### פורמט חלופי עם מבנה מקונן

```json
{
  "patients": [
    {
      "name": "רחל אברהם",
      "date": "2023-02-10",
      "age": 38,
      "diagnosis": "כאב צוואר",
      "treatment": "אקופונקטורה"
    }
  ]
}
```

### שדות נתמכים

המערכת מזהה אוטומטית שדות שונים. שדות מומלצים:

- **שם המטופלת**: `name`, `שם`, `patient_name`
- **תאריך**: `date`, `תאריך`, `visit_date`, `תאריך_ביקור`
- **גיל**: `age`, `גיל`
- **אבחנה**: `diagnosis`, `אבחנה`
- **טיפול**: `treatment`, `טיפול`
- **הערות**: `notes`, `הערות`, `remarks`

## 🎨 שימוש ב-Dashboard

### 1. העלאת קבצים
- לחץ על "בחר קבצי JSON"
- בחר 2-3 קבצים (או יותר)
- לחץ על "עבד ואחד קבצים"

### 2. צפייה בסטטיסטיקות
- סך הכל מטופלות
- כפולים שנמצאו
- קבוצות שמות דומים
- טווח תאריכים

### 3. בדיקת כפולים
- פתח את הסקציה "רשומות כפולות"
- בדוק רשומות שזוהו ככפולות
- החלט אם לאחד או להשאיר

### 4. זיהוי שמות דומים
- פתח את הסקציה "שמות דומים"
- בדוק קבוצות של שמות דומים
- זהה אם מדובר באותה מטופלת

### 5. ניתוח ציר זמן
- צפה בגרפים:
  - גרף קו - מגמת מטופלות לאורך זמן
  - גרף עמודות - התפלגות חודשית
  - מפת חום - פעילות לפי חודש ושנה

### 6. טבלת נתונים
- בחר עמודות להצגה
- סנן את הנתונים
- הורד כ-CSV לשימוש בהמשך

## 📊 תכונות מתקדמות

### זיהוי כפולים
המערכת משתמשת באלגוריתם המשלב:
- נרמול שמות (הסרת רווחים, המרה לאותיות קטנות)
- השוואת תאריכים
- זיהוי רשומות זהות

### זיהוי שמות דומים
המערכת משתמשת באלגוריתם Levenshtein Distance:
- חישוב דמיון בין שמות
- סף דמיון של 85% (ניתן להתאמה)
- קיבוץ שמות דומים לקבוצות

## 🔧 שימוש מתקדם - Python API

### שימוש ישיר בספריית העיבוד

```python
from data_processor import PatientDataProcessor

# יצירת מעבד
processor = PatientDataProcessor()

# עיבוד קבצים
results = processor.process_files([
    'data/patients_2023.json',
    'data/patients_2024.json'
])

# גישה לתוצאות
print(f"סך הכל מטופלות: {results['statistics']['total_patients']}")
print(f"כפולים: {results['duplicates_found']}")

# גישה ל-DataFrame
df = results['dataframe']
print(df.head())
```

## 💡 טיפים לשימוש

1. **ארגון קבצים**: שמור את קבצי ה-JSON בתיקיית `data/` לפני העלאה
2. **גיבוי**: הקבצים המאוחדים נשמרים ב-`output/merged_data.json`
3. **תאריכים**: וודא שהתאריכים בפורמט סטנדרטי (YYYY-MM-DD)
4. **שמות**: השתמש בשמות עקביים לזיהוי טוב יותר
5. **עברית**: המערכת תומכת באופן מלא בעברית
