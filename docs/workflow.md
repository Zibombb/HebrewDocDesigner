# ‏תהליך העבודה לפרשה

‏התהליך הזה תקף לכל פרשה. ‏השלבים רציפים: ‏אין לעבור לשלב הבא בלי לסיים את הקודם.

## ‏שלב 1 — ‏בחירת פרשה

‏נתונים נדרשים:
- ‏שם הפרשה בעברית (‏למשל: "‏תזריע")
- ‏שם באנגלית ‏ב-Sefaria (‏למשל: "Tazria")
- ‏הטווח הכתוב בהפניית Sefaria (‏למשל: `Leviticus 12:1-13:59`)

‏הטווח נשלף מתוך קובץ ה-schema ‏של הספר (‏שדה `alts.Parasha.nodes[].wholeRef`). ‏לא מהזיכרון, ‏לא מספירה ידנית.

## ‏שלב 2 — ‏הבאת הטקסט

‏מקור ראשי: `Sefaria-Export`, ‏מהדורת `merged` ‏בעברית.

```bash
curl -sS -o /tmp/{book}_he.json \
  "https://storage.googleapis.com/sefaria-export/json/Tanakh/Torah/{Book}/Hebrew/merged.json"
```

‏המבנה שחוזר: `text[chapter][verse]`, ‏מקונן לפי פרקים אז פסוקים. ‏ההיסט לפרשה נקבע לפי הטווח שנשלף בשלב 1.

‏שים לב: ‏הטקסט מכיל סימוני HTML ‏מסורתיים:
- `<b>׀</b>` — ‏פסיק (‏פַּסְקָא)
- `{פ}` ‏בתוך `<span class="mam-spi-pe">` — ‏פרשה פתוחה
- `{ס}` ‏בתוך `<span class="mam-spi-samekh">` — ‏פרשה סתומה
- `&thinsp;`, `&nbsp;` — ‏רווחים טיפוגרפיים
- `<br>` — ‏מעבר שורה

‏אין להשליך את הסימונים הללו לפני שלב בקרת האיכות. ‏החלטה מה לעשות איתם (‏לשמר, ‏להמיר למבנה סמנטי, ‏למחוק) ‏מתקבלת בנפרד לכל שכבה.

## ‏שלב 3 — ‏ניתוח מבנה

‏חישוב שלושה מדדים, ‏לאחר ניקוי סימוני HTML ‏וטעמי מסורה:

| ‏מדד | ‏שיטה |
|---|---|
| ‏פסוקים | ‏ספירת ערכים ברשימות הפרקים הרלוונטיים |
| ‏מילים | ‏פיצול על רווחים + ‏מקף + ‏פסיק. ‏מקף מפצל למילים נפרדות (‏שיטת המסורה). ‏רק יחידות שמכילות אות עברית. |
| ‏אותיות | ‏ספירת כל תו ב-`U+05D0..U+05EA` (‏כולל סופיות). ‏ללא ניקוד, ‏טעמים, ‏פיסוק. |

## ‏שלב 4 — ‏בקרת איכות

‏מקור בלתי־תלוי: `openscriptures/morphhb` ‏ב-GitHub, ‏מבוסס WLC (‏Westminster Leningrad Codex).

```bash
curl -sS -o /tmp/{book}_oshb.xml \
  "https://raw.githubusercontent.com/openscriptures/morphhb/master/wlc/{BookAbbrev}.xml"
```

‏שמות קצרים: `Gen`, `Exod`, `Lev`, `Num`, `Deut` (‏לוודא בכל ספר).

‏מריצים את אותו ניתוח מבנה (‏שלב 3) ‏על הטקסט השני. ‏שלושת המדדים חייבים להיות **‏זהים**.

- ‏התאמה מלאה ⇒ ‏עוברים לשלב 5
- ‏הבדל כלשהו ⇒ ‏עוצרים, ‏מנתחים את הפערים, ‏ומחליטים עם המשתמש

## ‏שלב 5 — ‏ניתוח גן גילה

‏ראה `docs/gan-gila-guide.md` ‏להנחיות מלאות. ‏תוצרים:

1. **‏רשימת סצנות** — ‏חלוקה נושאית של הפרשה ליחידות עצמאיות. ‏מבוססת על מעברים אמיתיים בטקסט, ‏לא על חלוקה דידקטית.
2. **‏פרומט אינפוגרפיקה לכל סצנה** — ‏תיאור ויזואלי מפורט באנגלית, ‏המיועד למנועי ייצור תמונות (‏Nano Banana, Midjourney, DALL-E, ‏וכד׳), ‏לפי הסגנון האחיד המוגדר.
