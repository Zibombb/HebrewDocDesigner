# ‏גן גילה — ‏מדריך

‏"‏גן גילה" ‏היא שכבת הפתיחה של הספר, ‏מעל הפשט. ‏התוכן המילולי הפשוט ביותר של הפרשה, ‏ברזולוציה שילד בן 4 ‏וכן מבוגר בן 40 ‏יכולים לעבור עליה באותה צורה.

## ‏מה גן גילה איננה

- ‏לא מדרש
- ‏לא פירוש
- ‏לא הקשר היסטורי
- ‏לא מוסר השכל
- ‏לא רגש (‏מלבד כשהטקסט עצמו מכיל רגש)
- ‏לא חלוקה דידקטית לפי מה ש"‏טוב ללמד"

## ‏מה גן גילה כן

- **‏רשימת סצנות** — ‏חלוקה נושאית של הטקסט ליחידות סגורות, ‏מבוססת על שיפטים פנימיים בטקסט עצמו.
- **‏לכל סצנה: ‏פרומט אינפוגרפיקה** — ‏תיאור ויזואלי מפורט המיועד למנועי AI ‏לייצור תמונות.

---

## ‏חלק א׳ — ‏שיטת החלוקה לסצנות

### ‏קריטריונים לשינוי סצנה

‏סצנה חדשה מתחילה כאשר הטקסט עצמו מבצע מעבר אחד או יותר:

1. **‏שינוי נושא מהותי** (‏לא רק פרט קזואיסטי בתוך אותו נושא)
2. **‏שינוי גיבור** — ‏למשל, ‏מאדם לחפץ, ‏ממצווה לכהן, ‏מקבוצה ליחיד
3. **‏מעבר מפרוצדורה לקיום** — ‏כשהטקסט עובר מ"‏מה עושים" ‏ל"‏איך חיים"
4. **‏שינוי במשטח או במדיום** — ‏גוף אדם, ‏בגד, ‏בית, ‏חפץ, ‏מקום
5. **‏פתיחה פורמלית** — ‏כשהטקסט מתחיל מחדש עם ביטוי כמו "‏וידבר ה׳", "‏אדם כי...", "‏ואיש או אשה כי...", "‏והבגד כי..."

### ‏קריטריונים ל**‏אי**־פיצול לסצנות

‏סצנות נפרדות אינן נוצרות כאשר:

- ‏הטקסט רק מונה תת־מקרים של אותה פרוצדורה (‏למשל: ‏עור, ‏שחין, ‏כוויה, ‏ראש, ‏זקן, ‏קרחת — ‏כולם אותו תהליך אבחון)
- ‏ההבדל הוא רק כמותי (‏שבעה ימים לעומת ארבעה־עשר)
- ‏יש רק שינוי לשוני בלי שינוי תוכני

### ‏גודל סצנה טיפוסי

‏מ-2 ‏עד 50 ‏פסוקים. ‏אין מספר קבוע. ‏פרק שלם יכול להיות סצנה אחת אם הוא נושא אחד סגור. ‏שני פסוקים יכולים להיות סצנה נפרדת אם הם מעבירים תוכן שונה מהותית מסביבתם.

### ‏מספר סצנות טיפוסי לפרשה

‏לרוב בין 3 ‏ל-8. ‏פחות מ-3 — ‏סימן שלא דייקנו. ‏יותר מ-8 — ‏סימן שכנראה פיצלנו תת־מקרים לשווא.

## ‏חלק ב׳ — ‏פרומט האינפוגרפיקה

‏לכל סצנה מכינים פרומט באנגלית שמיועד למנוע ייצור תמונות (‏Nano Banana / Gemini 2.5 Image, Midjourney, DALL-E, ‏או דומיהם).

### ‏סגנון ויזואלי אחיד — ‏חובה בכל פרומט

| ‏רכיב | ‏ערך |
|---|---|
| ‏טכניקה | `flat vector infographic illustration` |
| ‏קווים | `clean lines` |
| ‏איקונים | `symbolic icons` |
| ‏פלטת צבעים | `warm desert palette: sand, terracotta, olive, muted blue sky` |
| ‏תקופה | `ancient Israelite period, Mishkan-era` (‏כשרלוונטי) |
| ‏דמויות | `stylized figures in period tunics` |
| ‏יחס מסך | `3:2 aspect ratio` |
| ‏תוויות | ‏באנגלית קצרה בלבד |
| ‏צללים | ‏מינימליים |

### ‏איסורים

- ‏אין ציור פני הקב״ה
- ‏אין פרטי פנים של הכהן הגדול בפרטנות גבוהה
- ‏אין טקסט עברי ארוך בתוך התמונה (‏רוב המנועים לא מרנדרים עברית באמינות)
- ‏אין תיאור חצרות או עבודת קורבן בצורה מפורטת שעלולה להתפרש כלא צנועה

### ‏תבנית פרומט גנרית

```
Flat vector infographic illustration.
[‏תיאור הסצנה: ‏הרקע, ‏הדמויות, ‏הפעולה, ‏החפצים].
[‏רכיבי אינפוגרפיקה כשרלוונטי: ‏ציר זמן, ‏דיאגרמת החלטה, ‏מדליוני איקונים, ‏תוויות].
Warm desert palette: sand, terracotta, olive, muted blue sky.
Clean lines, symbolic icons, minimal shadows.
[‏Ancient Israelite setting / Mishkan era ‏כשרלוונטי].
Minimal English labels only.
3:2 aspect ratio.
```

### ‏שתי משפחות סצנות

1. **‏סצנה תהליכית / ‏פרוצדורלית** — ‏כשהפרשה מתארת מה עושים. ‏הפרומט בונה אינפוגרפיקה מסוג תרשים זרימה, ‏מדליוני מקרים, ‏צירי זמן, ‏או רצף שלבים.
2. **‏סצנה רגשית / ‏נרטיבית** — ‏כשהפרשה מתארת מצב אנושי, ‏חוויה, ‏או אירוע. ‏הפרומט בונה איור חד־תמונה עם קומפוזיציה שמעבירה את הרגש.

‏סצנות תהליכיות לרוב יותר נפוצות. ‏סצנות רגשיות נדירות יותר אבל הן "‏עוגני הזיכרון" ‏של הפרשה.

### ‏עקביות ויזואלית כסדרה

‏כל הסצנות בפרשה אחת חייבות להיראות כסדרה אחת:
- ‏אותה פלטת צבעים
- ‏אותו סגנון קווים
- ‏אותו יחס מסך
- ‏דמויות באותו סטיילינג

‏כשמריצים את כולן באותו מנוע באותה הרצה (session) — ‏זה מובטח יותר.
